# Smart Server Monitor

A Node.js and Express-based server monitoring dashboard.

## Features
- Live CPU usage monitoring
- RAM usage monitoring
- Real-time CPU and RAM charts
- Server health checks
- Start, stop, and restart controls
- Automatic crash recovery
- Activity logs

## Tech Stack
- Node.js
- Express.js
- HTML, CSS, JavaScript
- Node.js OS and Child Process modules

## Run Locally
1. Install Node.js.
2. Open the project folder in PowerShell.
3. Install dependencies:

   npm install

4. Start the application:

   npm start

5. Open http://localhost:3000 in your browser.

## Note
This project monitors the local system and manages a demo server on port 5000.
